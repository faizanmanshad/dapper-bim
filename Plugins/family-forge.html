How it works

Select Base Family

Choose a base element from your active Revit document (Beams, Columns, Walls, or Floors) using the intuitive dropdown UI.

Define Naming Format

Set your firm's custom naming standard. Use dynamic tags like {ID}, {W}, and {D} which will auto-increment and populate based on dimensions.

Generate & Inject

Click execute. Family Forge safely duplicates the base type, injects your precise dimension parameters, and bypasses native Revit lag.

Technical Specs

  • COMPATIBILITY Revit 2024
  • LICENSE TYPE Single PC / Hardware Locked
  • INTERNET REQUIRED Yes (For secure login)

Limitations

• Currently only supports Basic Walls (Stacked or Curtain walls are not supported in V1.0).

• Structural dimensions map to standard 'b' and 'h' parameters. Ensure your families use these shared parameters.

Installation

1. Download the `.exe` file from your User Portal.
2. Run the installer (Ensure Revit is closed).
3. Open Revit 2024. Navigate to the Add-Ins tab.
4. Click the Dapper.BIM icon and sign in with your portal credentials. The plugin is now permanently locked to your workstation.
